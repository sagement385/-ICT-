# NEMC 충북 범위 처리

공식 데이터포털 문서상 응급실 가용병상 endpoint의 지역 파라미터는 `STAGE1`(시도)과 `STAGE2`(시군구)이다.

2026-07-15 실제 호출 검증 결과:

- 파라미터 없이 호출하면 HTTP 200, 전국 416건이 반환됐다.
- `STAGE1`/`STAGE2`를 넣은 호출은 HTTP 200이지만 검증한 지역 조합에서 `totalCount=0`이었다.
- `Q0`는 해당 endpoint의 공식 지역 파라미터가 아니며, 코드에서 지역 필터로 사용하지 않는다.
- NEMC 실시간 응답에는 병원 주소 필드가 없었다.

따라서 현재 충북 전체 범위는 다음 순서로 제한한다.

1. HIRA 병원 기본목록에서 충북 코드(`330000`) 병원만 DB에 적재한다.
2. NEMC 전국 실시간 목록을 원본으로 저장한다.
3. NEMC `dutyName`과 이미 충북으로 제한된 HIRA 병원명을 정규화해 정확히 일치하는 기관만 병원별 실시간 상태와 연결한다.

이 방식은 NEMC의 지역 필터 응답이 실제로 정상적으로 동작하는지 확인되기 전까지 전국 기관을 충북 기관으로 잘못 분류하지 않는다. NEMC 응답의 `hv*` 상태 코드와 가용병상 의미는 공식 코드표를 확인하기 전까지 `null`로 보존한다.

## 2026-07-16 구현 결과

실시간 endpoint의 지역 파라미터에 의존하는 이전 보수적 연결을 공식 기관 목록 endpoint
`getEgytListInfoInqire` 기반으로 교체했다. 실제 응답에서 주소와 좌표 필드를 확인한 후에만
parser를 구현했다.

1. 전국 공식 응급의료기관 목록을 원본 그대로 저장한다.
2. `dutyAddr`가 `CHUNGBUK_REGION_NAME`으로 시작하는 기관만 선택한다.
3. NEMC `hpid`를 profile의 source ID로 보존한다.
4. 정규화된 기관명이 HIRA 병원 하나와 정확히 일치할 때만 연결한다.
5. 실시간 상태는 기관명 재매칭 없이 profile의 `hpid`로 연결한다.
6. 지도와 추천은 활성 profile이 있는 병원만 후보로 사용한다.

실제 확인 결과는 전국 534건, 충북 21건, HIRA 연결 21건, 미연결 0건, 중복 0건이다.
좌표 차이 경고 1건은 원본 좌표 불일치를 숨기지 않기 위해 profile에 기록했다. 이는 병원
자격을 추측하거나 임의로 제외하는 의료 기준이 아니다.

ITS 표준 노드·링크는 이 필터에 필요하지 않다. 향후 Naver Directions를 대체하거나
자체 경로 분석을 추가할 때 별도로 연계한다.
